# Reference Landing Spec

- Header/footer behavior: [ASSUMED] Sticky header, static footer
- Section heading style: [ASSUMED] Large uppercase, bold
- Class card anatomy: [ASSUMED] Image top, title, price, tagline, 'Choose Models' disclosure
- 'Choose Models' disclosure: [ASSUMED] Expands inline, chevron rotates, hover/focus state
- 'Price Coming Soon' styling: [ASSUMED] Muted text, italicized or specific treatment
- Disclaimer link behavior: [ASSUMED] Links to footer
- Card grid columns per breakpoint: [ASSUMED] 4 (≥1440), 3 (1024-1439), 2 (768-1023), 1 (<768)
- Lazy-load behavior: [ASSUMED] Skeleton loader for images

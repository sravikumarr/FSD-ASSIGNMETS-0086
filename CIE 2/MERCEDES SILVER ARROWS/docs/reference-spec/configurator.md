# Reference Configurator Spec

- Category list and order: Exterior, Wheels, Interior, Packages, Accessories, Summary
- Panel layout: [ASSUMED] Fixed width on right
- Stage layout: [ASSUMED] Fixed position on left
- Price-bar layout: [ASSUMED] Sticky at bottom
- Swatch/card/row patterns: [ASSUMED] Swatch grid for paint, card list for wheels, row list for packages
- Selected/hover/focus/disabled/loading states: [ASSUMED] Blue ring for focus, dark ring for selected
- Tooltips, drawers, modals: [ASSUMED] Drawers slide from right
- Conflict messages: [ASSUMED] Dialog showing removed/added options
- Summary view: [ASSUMED] Full list of categories with 'Edit' links
- Save flow: [ASSUMED] Opens a form to name build and save
- URL behavior: [ASSUMED] `?category=` push State

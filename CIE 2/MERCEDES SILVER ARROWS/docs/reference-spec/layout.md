# Reference Layout Spec

## Landing Page
- Grid columns: [ASSUMED] 4 columns at desktop, 3 at tablet, 1 at mobile
- Card sizes: [ASSUMED] Width 100%, aspect ratio 16:9 for images
- Padding/Margin/Gap: [ASSUMED] 24px gap, 48px section margin
- Sticky/fixed behavior: [ASSUMED] Header sticky

## Configurator Page
- Stage (left): [ASSUMED] ~65-70% width, light studio-style backdrop
- Panel (right): [ASSUMED] ~30-35%, fixed width 400-480px, category navigation on top, scrollable options below
- Bottom bar: [ASSUMED] height 72-88px, model name + price on left, actions on right
- Mobile: [ASSUMED] stage pinned at top, scrollable tab strip, sticky bottom bar, summary as full-screen sheet

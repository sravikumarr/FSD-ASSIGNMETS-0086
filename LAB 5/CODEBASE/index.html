Web Development Fundamentals

Behind the Build: Architecture & Engineering

Connecting this client-side interactive application to core industry software development and deployment concepts.

💻

Front-End vs. Back-End

DeskCraft is an entirely client-side web application running natively inside your browser using semantic HTML5, CSS3, and JavaScript. All state calculations, SVG graphics rendering, and storage happen locally without requiring a remote server database, ensuring instant responsiveness and privacy.

  • Client-Side: DOM rendering, UI event listeners, CSS transforms, LocalStorage API.
  • Back-End Potential: If extended, a Node.js / MySQL backend would store user accounts, process checkout orders, and sync setups across cloud devices.
🔄

Software Development Lifecycle (SDLC)

This project followed structured Agile SDLC stages: wireframing requirements, modular component architecture, iterative styling, functional integration, and automated QA verification.

  • Planning & Design: Wireframed workspace layouts, color palettes, and responsive breakpoints.
  • Implementation: Modular vanilla JS state management separating data from presentation.
  • Verification: Testing across mobile/desktop viewports, keyboard traps, and ARIA accessibility.
📱

Responsive Design & CSS Box Model

Built using modern CSS Grid and Flexbox with fluid clamp sizing and media queries. The interface adapts gracefully from small mobile screens (320px) to ultra-wide 4K monitors.

  • Box Model: Predictable sizing using box-sizing: border-box, precise padding/margin rhythms.
  • Media Queries: Fluid layout reorganization from stacked mobile controls to side-by-side desktop view.
🌿

Version Control & Git Workflow

Modern software engineering relies on Git for tracking revisions, safe feature branching, and collaborative peer reviews.

  • Feature Branches: Isolate new component features (e.g. feature/lighting-controls) before merging.
  • Atomic Commits: Clear commit messages following Conventional Commits format.
🧪

Testing & Quality Assurance

Quality is ensured through multi-layer testing: visual regression inspection, state mutation assertions, and accessibility compliance.

  • Functional Tests: Live assertions verifying price sums, preset loading, and slot resets.
  • Accessibility (a11y): WCAG AA contrast compliance, keyboard focus rings, and screen-reader live regions.
☁️

CI/CD & Cloud Deployment

Understanding the transition from local code to cloud production environments using automated pipelines and edge hosting.

  • Continuous Integration (CI): Automated test suites run on every Git pull request.
  • Continuous Delivery (CD) & Hosting: Deployed via static edge networks (GitHub Pages, Vercel, Netlify, Cloudflare Pages) with global CDN distribution.
